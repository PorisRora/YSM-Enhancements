## 中文

1.2.0 为 Minecraft 1.20.1 的 OpenYSM 2.6.6.6 接入了 Z 面板。同一个 1.20.1 增强包也适用于官方 YSM 2.6.5。1.21.1 增强包适用于官方 YSM 2.6.5。

| Minecraft | 安装包 | 最低 Fabric Loader |
|---|---|---|
| 1.20.1 | `ysm-enhancements-1.2.0-fabric-mc1.20.1.jar` | 官方 YSM 0.15.0，OpenYSM 0.16.10 |
| 1.21.1 | `ysm-enhancements-1.2.0-fabric-mc1.21.1.jar` | 官方 YSM 0.16.0 |

- OpenYSM 的模型菜单、作者参数、模型搜索和鼠标侧键已适配。关闭增强面板会恢复 OpenYSM 选定的原生轮盘。
- 修复女仆原生选模界面重建搜索框时的崩溃。两版官方 YSM 搭配 Orihime 均已实际换肤，回到世界后可以看到所选模型。
- OpenYSM 2.6.6.6 Fabric 的玩家选模和 Z 面板可用。该版本缺少女仆原生换肤联动，点女仆按钮会停在背包。

退出游戏，保留选用的模型模组和依赖，用表中的一个 JAR 替换客户端 `mods` 里的旧增强包。官方 YSM 与 OpenYSM 共用模组 ID，每个实例只装一种。[Forge / NeoForge 1.2.0](https://github.com/PorisRora/YSM-Enhancements/releases/tag/v1.2.0)

## English

Version 1.2.0 adds the Z panel to OpenYSM 2.6.6.6 on Minecraft 1.20.1. The same 1.20.1 addon supports official YSM 2.6.5. The separate 1.21.1 addon supports official YSM 2.6.5.

- OpenYSM support covers model menus, author-defined controls, search and mouse shortcuts. Disabling the panel restores the wheel selected in OpenYSM.
- Fixed a crash in the native maid model picker's search box handling. The native picker worked with Orihime on both official YSM builds. The chosen skin remained visible in the world.
- OpenYSM 2.6.6.6 Fabric supports the player picker and Z panel. That build lacks native maid skin integration.

Keep one model mod and its dependencies installed. With the game closed, replace the old addon in the client instance's `mods` folder with the JAR matching your Minecraft version. Minimum Fabric Loader for official YSM is 0.15.0 on 1.20.1 and 0.16.0 on 1.21.1. OpenYSM requires 0.16.10. [Forge / NeoForge 1.2.0](https://github.com/PorisRora/YSM-Enhancements/releases/tag/v1.2.0)
