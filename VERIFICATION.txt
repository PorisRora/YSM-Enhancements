YSM 体验优化（YSM Enhancements）1.1.0 验证记录
日期：2026-10-30
发布类型：正式版（v1.1.0）。

本版改动范围：按钮面板（交互修复、布局与键盘操作、界面美化）及共用反射工具的缓存优化；官方问题修复的逻辑未改动。

本版通过的检查（NeoForge 21.1.264 / MC 1.21.1 / YSM 2.6.5，JDK 21）：
- 编译与成品构建；双加载器元数据及成品版本为 1.1.0。
- 38 项输入回归（含原始 YSM 输入缓存类实测），5 个 YSM 类变换及操作数检查，实际 Mixin 注入检查。
- 111 项实际反射成员/签名核对，新增点击音效、YSM 分页记录及文件夹路径结构的核对。
- 真实滑条输入回调与缩放滑条默认值；真实 YSM 解析器的缩放表达式分析（本版未使用模型包）。
- 面板交互回归：导航键不再落到隐藏的原轮盘控件、焦点跟随目标、键盘自动滚动、数值输入、滚动条拖动。
- NVIDIA GeForce RTX 4060 Laptop GPU 隐藏窗口 OpenGL 深度隔离测试。

发布前重新构建并运行上述检查，包含最后一次提交新增的“返回页面不恢复过期悬停状态”和“右方向键移到相邻播放按钮”回归，均通过。
构建时通过临时 Gradle init 脚本向 compileOnly 补充本机 FML 4.0.45 API（默认引用的 4.0.44 不在本机）；该依赖不打入成品。

本版未重新运行：Forge 47.4.16 / MC 1.20.1 的全部测试（本机没有 Forge 版 YSM 2.6.5），以及原生配置读写测试（配置代码未改动）。新增的反射名称已对照 1.20.1 SRG 客户端 jar 核对存在。
限制：未在游戏内实机确认面板画面。

YSM 体验优化（YSM Enhancements）1.0.0 验证记录
日期：2026-10-19
发布类型：正式版（v1.0.0）。

对比基准：官方 YSM 2.6.5。

相对官方的新增功能：
- 模型驱动的 Z 按钮面板，支持菜单分页、参数滚动、数值输入和键盘操作。
- 可旋转、缩放及复位的模型预览。
- 加载器原生配置入口，按钮面板与各项修复可独立控制，默认全部开启。

官方问题修复：
- 清理切窗口、打开界面或松开按键后的残留按住状态。
- 动作锁定快捷键检查修饰键与游戏操作环境。
- 鼠标按钮快捷键转交给 YSM 原有动作逻辑。
- 阻止官方轮盘可见区域外的隐藏控件响应点击。
- 滚动及异步加载后更新上下箭头状态。
- 正确读取科学计数法变量。
- 按明确的模型零值回退规则初始化超出范围的缩放滑条显示，不写入模型变量。
- 负数且非零的变量显示为已勾选。
- 模型搜索列表重建时保留光标、选区和文本显示位置。
- 丢弃旧配置页或已关闭界面的延迟控件回调。

实现核对：
- 只读核对两版 Minecraft AbstractWidget 的实际字节码：垂直居中使用 (上边界 + 下边界 - 9) / 2 + 1。
- 按钮和标签基于绘制矩形及字体 lineHeight 统一计算位置；根目录、返回和动作锁定使用同一条标题行。
- 文字超长时先截短并加入省略号，再计算显示宽度；截短边界使用 Unicode 码点。
- 选项组按实际控件类型显示选中或未选中的圆点，点击继续触发作者定义的回调和表达式。
- 零值回退显示修复由 fixes.scaleDefaults 独立控制，默认开启；在 Mods 配置中的名称为“修复缩放滑条首次显示”。

本版通过的检查：
- Java 17 目标构建，双加载器元数据及成品版本为 1.0.0。
- NeoForge 21.1.249 / MC 1.21.1 / YSM 2.6.5：38 项输入回归，104 项实际反射成员/签名核对，5 个 YSM 类变换及操作数检查，实际 Mixin 注入检查。
- Forge 47.4.16 / MC 1.20.1 / YSM 2.6.5：38 项输入回归，103 项实际反射成员/签名核对，5 个 YSM 类变换及操作数检查，实际 Mixin 0.8.5 注入检查。
- 两种命名下的面板焦点、拖动旋转、姿态恢复和异步重建保留滚动位置回归。
- 成品资源、字节码、双加载器元数据检查；两种入口注解均绑定 ysm_enhancements，Mixin 与翻译资源使用同一 MODID。没有打包 YSM/Minecraft/加载器/测试夹具类；原始 YSM jar 哈希未变。

专项验证记录：
- 真实 YSM 解析器识别明确的缩放零值回退；Rooboko 模型 55 个相关表达式中，player_size/head/tair_size 的回退值为 1。
- 两版真实滑条算术验证显示初始化不写变量、第一次方向键从 1 变为 1.05。
- AMD Radeon RX 7900 XT 隐藏窗口 OpenGL 深度隔离测试：自身遮挡、裁剪边界和状态恢复。
- 两版加载器原生配置默认值、独立开关及 TOML 保存验证。

限制：未在完整游戏整合包中启动本版进行画面实测。需在实际资源包与 GUI 缩放下复核动作锁定、返回、目录标题、百分比和参数标签的对齐；特殊字体的字形可能影响视觉中心。
本补丁未覆盖或修改模型、YSM 原 jar 或存档。
